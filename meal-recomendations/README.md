To install dependencies:
```sh
bun install
```

To run:
```sh
bun run dev
```

open http://localhost:3000

## Konfiguracja

Do prawidłowego działania serwera wymagany jest klucz API Google Gemini.

W głównym katalogu projektu należy utworzyć plik `.env` i umieścić w nim następującą zmienną:

```env
GEMINI_API_KEY=twój_klucz_api
```
